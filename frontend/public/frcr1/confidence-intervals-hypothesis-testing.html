Confidence Intervals & Hypothesis Testing

Estimation, confidence intervals, p-values, Type I & II errors, power, and one-tailed vs two-tailed tests — from GCSE to FRCR level.

Standard Error & Confidence Intervals

Standard Error of the Mean (SEM) = SD / √n. It measures how precisely the sample mean estimates the population mean. Larger samples → smaller SEM.

Confidence Interval (CI): A range of values that is likely to contain the true population parameter. A 95% CI for the mean is: mean ± 1.96 × SEM.

Interpretation: If you repeated the study 100 times, about 95 of the CIs would contain the true population mean.

⚠️ Common Misunderstanding
A 95% CI does NOT mean "there is a 95% chance the true value lies in this interval." It means "95% of intervals constructed this way will contain the true value." This is a subtle but important distinction for the FRCR exam.

Hypothesis Testing & p-values

Null hypothesis (H₀): No difference / no effect (e.g., "the new drug is no different from placebo").

Alternative hypothesis (H₁): There is a difference / effect (e.g., "the new drug is different from placebo").

p-value: The probability of observing the data (or more extreme) assuming H₀ is true. A small p-value (< 0.05) means the observed result is unlikely under H₀, so we "reject H₀" — the result is "statistically significant."

Important: p < 0.05 does NOT mean the effect is clinically important. It only tells you the result is unlikely due to chance.

Confidence Intervals in Detail

95% CI for the mean (when σ is known or n is large): x̄ ± 1.96 × SEM.

95% CI for the mean (when σ is unknown, n small): x̄ ± t(n−1) × SEM, where t(n−1) is the critical value from the t-distribution with n−1 degrees of freedom. The t-distribution has fatter tails than the normal when n is small, producing wider CIs — accounting for the additional uncertainty of estimating σ from the sample.

95% CI for a proportion: p̂ ± 1.96 × √(p̂(1 − p̂) / n). Only valid when np̂ and n(1−p̂) are both > 5.

95% CI for RR or OR: Usually calculated on the log scale (ln OR ± 1.96 × SE(ln OR)) then exponentiated back. If the CI includes 1, the result is not statistically significant.

Factors affecting CI width:

  • Sample size (n): Larger n → narrower CI (SEM decreases).
  • Variability (SD): Larger SD → wider CI.
  • Confidence level: 99% CI is wider than 95% CI.

Figure 2: Factors affecting CI width. Larger n narrows the CI (top three). Higher confidence level widens the CI (bottom two, same n). All CIs with the point estimate to the right of zero are statistically significant.

CIs vs p-values: CIs are generally preferred because they show the range of plausible effect sizes, not just whether the result is "significant." A CI can tell you both whether the result is statistically significant (does it exclude the null?) and clinically important (is the smallest plausible effect meaningful?).

⚠️ Exam Trap: CI Width Interpretation
A wide CI does not necessarily mean "no effect" — it may mean the study was too small to estimate the effect precisely. Always look at the CI width as a measure of precision, not just whether it includes the null.

Hypothesis Testing Framework — Step by Step

The five formal steps:

  1. State H₀ and H₁: Clearly define the null and alternative hypotheses. For a two-tailed test: H₀: μ₁ = μ₂, H₁: μ₁ ≠ μ₂.
  2. Choose significance level α: Usually 0.05 (5% chance of Type I error).
  3. Select appropriate test statistic: Depends on data type, distribution, number of groups, and whether data is paired or independent.
  4. Calculate test statistic and associated p-value: Compare observed statistic to theoretical distribution.
  5. Make a decision: If p < α, reject H₀ (result statistically significant). If p ≥ α, fail to reject H₀ (insufficient evidence to conclude a difference).

Never say "accept H₀" — we only "fail to reject" it. The absence of evidence is not evidence of absence.

Type I error (α): Rejecting H₀ when it is true. "False positive." Conventionally set at 0.05. The risk of concluding a difference exists when it does not.

Type II error (β): Failing to reject H₀ when it is false. "False negative." Probability depends on effect size, sample size, and α.

Power (1 − β): Probability of correctly rejecting H₀ when it is false (i.e., detecting a true effect). Adequate power (≥ 0.80) is essential for study design.

Trade-off: Decreasing α reduces Type I error but increases Type II error (reduces power). The only way to reduce both errors is to increase sample size.

One-tailed vs Two-tailed Tests

Two-tailed test (most common in medical research): Divides α equally between both tails. H₁: μ₁ ≠ μ₂. Tests for a difference in either direction. More conservative — requires a larger effect to reach significance.

One-tailed test: Places all α in one tail. H₁: μ₁ > μ₂ (or μ₁ < μ₂). Tests for a difference in a specified direction. More powerful (lower p-value for same effect) but rarely justified in medical research.

When to use one-tailed: Only when a difference in the opposite direction is impossible or clinically irrelevant. Example: comparing a new drug to placebo where the drug cannot possibly be worse (though this is almost never true — drugs can have harmful effects).

Figure 1: Two-tailed test splits α equally between both tails (critical value ±1.96). One-tailed places all α in one tail (critical value 1.645) — more powerful but requires strong pre-specified justification.

⚠️ Exam Trap: One-tailed misuse
FRCR exam questions often test this: if a study uses a one-tailed test without strong justification, it is considered a methodological flaw. Two-tailed tests are the default in medical research. A paper that switches from two-tailed to one-tailed after seeing the results is committing p-hacking.

p-value Misinterpretations

The p-value is one of the most misunderstood concepts in statistics. Common misinterpretations to avoid:

  • NOT the probability that H₀ is true — it is P(data | H₀), not P(H₀ | data).
  • NOT the probability that the result occurred by chance — it is the probability of observing this result (or more extreme) if chance alone is operating.
  • NOT a measure of effect size — a tiny p-value can occur with a trivial effect if the sample is large enough.
  • NOT a measure of clinical importance — p < 0.001 does not mean the treatment is clinically meaningful.
  • p > 0.05 does NOT mean "no difference" — it means "insufficient evidence to reject H₀." The study may be underpowered.

Better alternatives: Report CIs and effect sizes alongside p-values. The CI gives the range of plausible effects, which is far more informative than a binary "significant/not significant."

Essential Exam Facts

95% CI for mean = mean ± 1.96 × SEM (large n) or ± t × SEM (small n).
CI width reflects precision: wider = less precise.
If 95% CI for RR/OR includes 1: NOT statistically significant.
p-value = P(data | H₀), NOT P(H₀ | data).
Type I error (α): false positive (reject true H₀). Usually α = 0.05.
Type II error (β): false negative (fail to reject false H₀).
Power = 1 − β. Minimum acceptable power = 0.80.
Two-tailed: preferred default. One-tailed: needs strong justification.
p > 0.05 = insufficient evidence, NOT "no difference."
CIs preferred over p-values — show range of plausible effects.
⚠️ Common Exam Traps
• "95% CI includes the null" is equivalent to p > 0.05 — but the CI tells you more because it shows how wide the range of plausible effects is.
• Switching from two-tailed to one-tailed post hoc is p-hacking.
• A significant p-value from a small study may be a false positive (underpowered studies that happen to be significant often have inflated effect sizes — the "winner's curse").
• p = 0.04 in a study with 20 subgroup analyses is NOT significant after multiple testing correction.
🏥 Why This Matters Clinically

Interpreting trial results: When a paper reports "HR = 0.75 (95% CI: 0.60–0.94, p = 0.01)", the CI tells you the true hazard ratio could be as low as 0.60 (very beneficial) or as high as 0.94 (barely beneficial). Both are clinically meaningful, but the range matters for clinical decision-making.

The problem with "p < 0.05" as a threshold: Many clinicians equate "statistically significant" with "clinically important." A large study might find p < 0.001 for a 0.5 mmHg blood pressure reduction — statistically significant but clinically trivial. Conversely, a small study might show p = 0.07 for a clinically meaningful survival benefit — not significant statistically but worth further investigation.

Non-inferiority trials: These flip the hypothesis testing framework. H₀ is that the new treatment is WORSE than the control by more than a pre-specified margin. Rejecting H₀ shows non-inferiority. The CI approach is essential: if the upper bound of the 95% CI for the difference does not exceed the non-inferiority margin, non-inferiority is demonstrated.

Bayesian vs frequentist: The p-value framework is frequentist — probability is defined as long-run frequency. Bayesian approaches (posterior probabilities, credible intervals) are increasingly used in medical research but are not yet standard in FRCR.

📐 Worked Examples

Scenario: A study reports the mean difference in survival between two treatments as 4.2 months (95% CI: −0.3 to 8.7 months). What can you conclude?

Solution: The 95% CI includes zero (no difference). Therefore, the result is NOT statistically significant (p > 0.05). However, the upper limit suggests a potential benefit up to 8.7 months. The study may be underpowered. The clinical conclusion: insufficient evidence to conclude a difference exists, but the observed effect is compatible with a clinically meaningful benefit — a larger study is needed.

Key insight: Do NOT say "the treatment doesn't work." Say "we cannot conclude the treatment is effective based on this study." These are different statements.

Scenario: A small pilot study (n = 20 per group) compares a new drug to placebo and finds p = 0.30 for the primary endpoint. The researchers conclude "the drug has no effect." What error might they be making?

Solution: They may be making a Type II error (false negative). With n = 20 per group, the study likely has low power to detect a clinically meaningful effect. p = 0.30 does NOT mean the drug has no effect — it means the study could not detect a statistically significant difference. The drug might still be effective; a larger study is needed.

Clinical relevance: Many potentially useful treatments have been abandoned based on underpowered studies. Conversely, many ineffective treatments have been adopted based on underpowered studies that happened to show significant results (Type I error).

Scenario: A trial compares a new analgesic to placebo for post-operative pain. The protocol specified a two-tailed test. After the results came in showing a pain reduction of 1.2 points (p = 0.08 two-tailed), the authors re-analysed using a one-tailed test (p = 0.04) and reported "significant pain reduction." Is this valid?

Solution: No — this is post-hoc switching to one-tailed, a form of p-hacking. If the effect was in the opposite direction (pain worse), they would not have reported it as significant. A one-tailed test must be pre-specified in the protocol. The correct conclusion is p = 0.08, not significant.

FRCR exam point: One-tailed tests are pre-specified, not data-driven. If a study switches from two-tailed to one-tailed after seeing the data, it introduces bias.

🧠 Active Recall Questions

  • Q: What is the correct interpretation of a 95% CI?
    A: If you repeated the study 100 times, approximately 95 of the CIs would contain the true population parameter. It is NOT the probability that the true value lies in this particular interval.
  • Q: What is the relationship between a 95% CI and a p-value?
    A: If the 95% CI does not include the null value (0 for differences, 1 for RR/OR), then p < 0.05. If the CI includes the null, then p > 0.05.
  • Q: Define Type I and Type II errors.
    A: Type I (α): rejecting H₀ when true — false positive. Type II (β): failing to reject H₀ when false — false negative. Power = 1 − β.
  • Q: Why are two-tailed tests preferred in medical research?
    A: They are more conservative and test for effects in either direction. One-tailed tests require strong prior justification that a difference in the opposite direction is impossible.
  • Q: What does p = 0.06 mean?
    A: There is a 6% probability of observing the data (or more extreme) if H₀ is true. It is NOT statistically significant at the 0.05 threshold, but it does NOT mean "no effect" — the study may be underpowered.

📖 Glossary

Confidence Interval
Range of plausible values for a population parameter. 95% = repeated sampling interpretation.
p-value
P(observed data or more extreme | H₀ true). NOT P(H₀ | data).
Null hypothesis (H₀)
Default assumption: no difference, no effect, no association.
Type I Error
False positive. Rejecting H₀ when true. Probability = α (usually 0.05).
Type II Error
False negative. Failing to reject H₀ when false. Probability = β.
Power
1 − β. Probability of detecting a true effect. Minimum 0.80.
Significance level (α)
Threshold for rejecting H₀. Usually 0.05.
One-tailed test
Tests effect in one direction. All α in one tail. Needs pre-specification.
Two-tailed test
Tests effect in either direction. α split between tails. Default in medical research.
Effect size
Magnitude of the difference or association. Clinically important regardless of p-value.
p-hacking
Repeated analyses, data dredging, or post-hoc test switching to achieve p < 0.05.
