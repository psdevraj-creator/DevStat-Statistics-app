Logistic Regression

Binary, multinomial and ordinal logistic regression; odds ratios; maximum likelihood estimation; goodness-of-fit; model comparison — GCSE to FRCR level.

What is Logistic Regression?

Logistic regression is used when the outcome variable is binary (yes/no, alive/dead, recurrence/no recurrence). Unlike linear regression which predicts a continuous number, logistic regression predicts the probability of an event occurring.

Example: Can we predict whether a patient will have a tumour recurrence (yes/no) based on radiation dose, age, and tumour stage?

Key idea: Instead of predicting "yes" or "no" directly, logistic regression predicts the log-odds of the event, then converts this back to a probability. This keeps the prediction between 0 and 1 (valid for probabilities).

Figure 1: The logistic (sigmoid) function maps any log-odds value to a probability between 0 and 1. At log-odds = 0, p = 0.5. The OR = exp(β₁) gives the multiplicative change in odds per unit increase in the predictor.

Logistic Regression Model — Full Detail

Model equation (predicting log-odds of outcome):

log(p / (1−p)) = β₀ + β₁x₁ + β₂x₂ + ... + βₖxₖ

where p = P(Y = 1 | X), the probability of the outcome given the predictors.

Converting log-odds to probability: p = exp(β₀ + β₁x₁ + ...) / (1 + exp(β₀ + β₁x₁ + ...))

Odds Ratio (OR) = exp(βᵢ). The multiplicative change in odds of the outcome per unit increase in predictor xᵢ, adjusted for other predictors.

  • OR = 1: no association.
  • OR > 1: predictor increases odds of outcome (risk factor).
  • OR < 1: predictor decreases odds of outcome (protective factor).

Example interpretation: If β_smoking = 1.5, then OR = exp(1.5) = 4.48. Smokers have 4.48 times the odds of lung cancer compared to non-smokers, adjusted for other predictors in the model.

⚠️ Exam Trap: OR vs RR
Logistic regression gives ODDS ratios, not risk ratios. When the outcome is common (>10%), OR is larger than RR. Many researchers mistakenly interpret OR as RR — this is a common error in the literature. For rare outcomes (<10%), OR ≈ RR.

Figure 2: Odds ratio interpretation. OR < 1 = protective, OR = 1 = no association, OR > 1 = increased odds. If the 95% CI crosses 1, the result is not statistically significant.

Maximum Likelihood Estimation (MLE)

Unlike linear regression which uses least squares (minimising sum of squared residuals), logistic regression uses maximum likelihood estimation.

How MLE works: The computer searches for the β values that maximise the likelihood — the probability of observing the data given the model. The likelihood function is: L(β) = Π p(xᵢ)^yᵢ × (1−p(xᵢ))^(1−yᵢ).

In practice, we maximise the log-likelihood (easier computationally). Iterative algorithms (Newton-Raphson, Fisher scoring) are used because there is no closed-form solution.

Why not least squares? The response is binary (0 or 1), so residuals are not normally distributed and variance is not constant. MLE handles these properties naturally.

Goodness-of-Fit for Logistic Regression

R² in linear regression cannot be directly applied. Instead, we use pseudo-R² measures:

  • McFadden's R² = 1 − (logL_model / logL_null). Typically 0.2–0.4 indicates excellent fit (much lower than linear R²).
  • Nagelkerke's R²: Scaled to range 0–1. More familiar interpretation but still not directly comparable to linear R².

Hosmer-Lemeshow test: Groups observations by predicted probability, then tests whether observed vs expected event rates differ within groups. A significant test (p < 0.05) indicates poor fit. However, it is sensitive to sample size — may detect trivial misfit in large samples.

Model comparison:

  • AIC (Akaike Information Criterion): −2logL + 2k (k = number of parameters). Lower AIC = better fit, penalising complexity. Used for model selection.
  • BIC (Bayesian Information Criterion): −2logL + k×ln(n). Penalises complexity more than AIC. Prefers simpler models.
  • Likelihood ratio test: Compares nested models. LR = −2(logL_reduced − logL_full). Follows χ² distribution with df = difference in number of parameters.

Multinomial & Ordinal Logistic Regression

Multinomial logistic regression: For outcomes with > 2 unordered categories (e.g., tumour response: CR, PR, SD, PD). One category is chosen as the reference, and separate log-odds equations are estimated for each other category vs the reference.

Ordinal logistic regression: For > 2 ordered categories (e.g., ECOG 0, 1, 2, 3). Uses the proportional odds assumption: the effect of each predictor is assumed to be the same across all thresholds (e.g., the OR for being in a higher ECOG category vs a lower one is constant regardless of which threshold you consider).

Checking proportional odds: Brant test (or likelihood ratio test comparing constrained vs unconstrained model). If violated (p < 0.05), use multinomial logistic regression (which does not assume proportional odds) or partial proportional odds models.

Sample Size for Logistic Regression

Rule of thumb: Minimum 10 events per predictor variable (EPV). The "event" is the less frequent outcome category. If you have 50 events and 30 non-events, the event count is 50 — you can support ~5 predictors.

Low EPV leads to overfitting, inflated coefficients, and poor generalisability. Some simulation studies suggest EPV ≥ 20 for reliable estimation.

Essential Exam Facts

Logistic regression: binary outcome. Models log-odds of event.
OR = exp(β). Multiplicative change in odds per unit increase in predictor.
OR is adjusted for all other predictors in the model.
Maximum likelihood estimation (MLE) — not least squares.
No normality assumption. No homoscedasticity assumption.
Pseudo-R²: McFadden's, Nagelkerke's. Much lower than linear R².
Hosmer-Lemeshow test: tests goodness-of-fit. Significant = poor fit.
AIC/BIC for model comparison. Lower = better fit, penalising complexity.
Multinomial: >2 unordered categories. Ordinal: >2 ordered categories.
Proportional odds assumption for ordinal logistic regression.
10 events per predictor variable (EPV) minimum.
⚠️ Common Exam Traps
• Logistic regression gives OR, NOT RR. OR > RR when outcome is common (>10%).
• The coefficients are log-odds — you must exponentiate them to get OR.
• Pseudo-R² values are NOT comparable to linear R². A "good" pseudo-R² may be 0.2–0.4.
• The proportional odds assumption must be checked for ordinal logistic regression.
• Inadequate EPV leads to overfitting — coefficients may be unreliable.
• "Adjusted OR" means the OR controls for other variables — important for confounder control.
🏥 Why This Matters Clinically

Risk factor identification: Logistic regression is the standard method for identifying independent risk factors for binary outcomes (post-operative complications, tumour recurrence, treatment response). A multivariable model can show which factors are independently predictive after controlling for confounders.

Prognostic models in oncology: The TNM staging system and many prognostic indices are derived from logistic regression or Cox regression. Understanding how adjusted ORs are computed is essential for interpreting published prognostic models.

Propensity score analysis: Logistic regression is used to estimate propensity scores — the probability of receiving treatment given baseline covariates. This is a key method for reducing confounding in observational studies.

Critical appraisal: When reading a paper using logistic regression: (1) Did they check the EPV rule? (2) Did they report pseudo-R²? (3) Did they do a Hosmer-Lemeshow test? (4) Did they interpret ORs correctly (not as RR)? (5) Did they check the proportional odds assumption for ordinal outcomes? (6) Did they report AIC/BIC for model comparison?

📐 Worked Examples

Scenario: A logistic regression models tumour recurrence (yes/no) on dose (Gy), age (years), and smoking (0/1). Output: β_dose = −0.05 (p = 0.02), β_age = 0.02 (p = 0.30), β_smoking = 1.2 (p = 0.004). Interpret.

Solution: For dose: OR = exp(−0.05) = 0.95 per Gy. Each additional Gy reduces the odds of recurrence by 5% (95% CI would show if this is clinically meaningful), adjusted for age and smoking. Significant (p = 0.02).

For age: OR = exp(0.02) = 1.02 per year. Not significant (p = 0.30) — insufficient evidence that age affects recurrence after adjusting for dose and smoking.

For smoking: OR = exp(1.2) = 3.32. Smokers have 3.32 times the odds of recurrence compared to non-smokers, adjusted for dose and age. Significant (p = 0.004).

Scenario: A study plans to include 6 predictors in a logistic regression model predicting post-operative mortality. The anticipated event rate is 15%. How many patients are needed?

Solution: Minimum 10 events per predictor → 6 × 10 = 60 events needed. With 15% event rate: n = 60 / 0.15 = 400 patients.

For more reliable estimates (EPV ≥ 20): 6 × 20 = 120 events. n = 120 / 0.15 = 800 patients.

Key insight: The sample size calculation depends on the number of EVENTS, not the total sample size. A study with 400 patients but only 30 events (7.5% rate) and 6 predictors has EPV = 5 — inadequate.

🧠 Active Recall Questions

  • Q: What does logistic regression model?
    A: The log-odds of a binary outcome. log(p/(1-p)) = β₀ + β₁x₁ + ... The OR = exp(β) gives multiplicative change in odds.
  • Q: How does estimation differ between linear and logistic regression?
    A: Linear regression uses least squares. Logistic regression uses maximum likelihood estimation (MLE) because the outcome is binary.
  • Q: What is the 10 EPV rule?
    A: Minimum 10 events per predictor variable in logistic regression. Inadequate EPV leads to overfitting and unreliable coefficients.
  • Q: What is the proportional odds assumption?
    A: In ordinal logistic regression, the effect of each predictor is the same across all thresholds. Checked by Brant test. If violated, use multinomial logistic regression.
  • Q: Compare AIC and BIC.
    A: Both are model fit metrics that penalise complexity. AIC = −2logL + 2k. BIC = −2logL + k×ln(n). BIC penalises complexity more heavily. Lower values = better fit.
