Non-Parametric & Categorical Tests

Chi-square, Fisher's exact, McNemar's, Mann-Whitney, Wilcoxon, Kruskal-Wallis, Spearman, and Friedman tests — GCSE to FRCR level.

Chi-Square (χ²) Test for Association

Used to test whether two categorical variables are associated. For example: is there a relationship between smoking (yes/no) and lung cancer (yes/no)?

How it works: Compare observed frequencies in each cell of a contingency table to the frequencies expected if there were no association. If observed and expected differ substantially, the result is significant.

Expected frequency = (row total × column total) / grand total.

Test statistic: χ² = Σ(O − E)² / E.

Fisher's Exact Test

Used instead of chi-square when sample sizes are small (expected frequency < 5 in any cell). It calculates the exact probability of the observed table under the null hypothesis — no approximation needed.

Chi-Square (χ²) Test for Independence — Full Detail

Use: Tests association between two categorical variables in a contingency table. Example: treatment group (A vs B) vs outcome (alive vs dead).

Formula: χ² = Σ(Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ, where O = observed frequency, E = expected frequency.

Expected frequency Eᵢⱼ = (row total_i × column total_j) / grand total.

Degrees of freedom: (rows − 1) × (columns − 1). For a 2×2 table, df = 1. For 3×2 table, df = 2.

Assumptions:

  1. No more than 20% of expected frequencies < 5.
  2. All expected frequencies ≥ 1.
  3. Independent observations — each person counted once (no matched or paired data).
  4. Data is a random sample from the population.

Yates' continuity correction: Applied to 2×2 tables to reduce Type I error. Adjusts formula: χ² = Σ(|O − E| − 0.5)² / E. However, Yates' correction is conservative — Fisher's exact test is preferred for small samples.

Figure 1: Chi-square test. Compare observed (O) to expected (E) frequencies. Green cells: O > E; orange cells: O < E. Large differences produce a large χ² statistic. If any expected cell < 5, use Fisher's exact test.

⚠️ Exam Trap: Chi-Square Assumptions
FRCR exam questions often test whether you know to use Fisher's exact test when chi-square assumptions are violated. Rule: if ANY expected frequency < 1, or >20% of expected frequencies < 5, use Fisher's exact test.

Fisher's Exact Test

Use: When chi-square assumptions are violated (small expected frequencies). Also appropriate for 2×2 tables regardless of sample size — some statisticians prefer it as the default for 2×2 tables.

How it works: Calculates the exact probability of the observed table (and all more extreme tables) under H₀ using the hypergeometric distribution. No approximation — hence "exact."

The probability of a particular 2×2 table is: P = (a+b)! (c+d)! (a+c)! (b+d)! / (n! a! b! c! d!), where a, b, c, d are cell frequencies.

One-tailed vs two-tailed: Fisher's test can compute both. Most software gives two-tailed p-value by summing probabilities of all tables as or more extreme in either direction.

Computational limitation: With very large samples, the factorial calculations become computationally intensive — but this is rarely a problem with modern computers and is not testable in FRCR.

McNemar's Test for Paired Categorical Data

Use: For paired categorical data — before/after measurements on the same subjects, or matched case-control data. Example: testing whether a new diagnostic test agrees with the gold standard in the same set of patients.

How it differs from chi-square: Chi-square assumes independence. McNemar's explicitly accounts for the pairing by focusing only on discordant pairs — subjects who changed from yes→no or no→yes. Concordant pairs (yes→yes, no→no) are ignored because they contribute no information about the change.

Formula: χ² = (b − c)² / (b + c), where b = number of pairs that changed from no→yes, c = number that changed from yes→no. df = 1.

Continuity correction: χ² = (|b − c| − 1)² / (b + c).

Example: 100 patients tested before and after treatment. 30 improved (no→yes), 10 worsened (yes→no), 60 unchanged. χ² = (30−10)²/(30+10) = 400/40 = 10.0. df=1, critical = 3.84 → significant.

Non-Parametric Tests — Overview

What are they? Tests that make no assumptions about the underlying distribution of the data. They are based on ranks rather than raw values, so they are robust to outliers and skew.

Efficiency: Non-parametric tests have ~95% of the power of parametric tests when assumptions are met, but can be substantially more powerful when they are not. This makes them a safe default for skewed or ordinal data.

Mann-Whitney U Test (Wilcoxon Rank-Sum)

Use: Non-parametric alternative to independent t-test. Compares two independent groups. Tests H₀: the distributions are identical (or the two groups come from the same population).

How it works:

  1. Rank all values from both groups together (1 = smallest, N = largest).
  2. Sum the ranks for each group (R₁ and R₂).
  3. Calculate U = n₁n₂ + n₁(n₁+1)/2 − R₁ (or equivalent formula).
  4. Compare U to its sampling distribution (or convert to z-score for large samples).

Interpretation: If one group tends to have higher ranks than the other, the U statistic is extreme and the result is significant.

Effect size: Can report r = z / √N, where r ≈ 0.1 (small), 0.3 (medium), 0.5 (large). Or report the median difference with its CI.

Wilcoxon Signed-Rank Test

Use: Non-parametric alternative to paired t-test. For paired data (before/after, matched pairs). Tests H₀: median difference = 0.

How it works:

  1. Calculate the difference for each pair.
  2. Discard zeros.
  3. Rank the absolute differences (1 = smallest absolute difference).
  4. Separately sum ranks of positive differences (W⁺) and negative differences (W⁻).
  5. The test statistic is the smaller of W⁺ and W⁻.

Assumption: The distribution of differences is symmetric (less stringent than normality).

Kruskal-Wallis Test

Use: Non-parametric alternative to one-way ANOVA. Compares ≥ 3 independent groups. Extends Mann-Whitney to more than two groups.

How it works: Ranks all data from all groups together, then compares mean ranks between groups. H-statistic ≈ χ² distribution with (k−1) df.

Post-hoc: If Kruskal-Wallis is significant, use Dunn's test with Bonferroni correction for pairwise comparisons (the non-parametric equivalent of Tukey HSD).

Spearman's Rank Correlation (ρ)

Use: Non-parametric alternative to Pearson correlation. Measures strength of monotonic (not necessarily linear) relationship between two variables.

How it works: Apply Pearson correlation to the ranks of the data rather than raw values.

Interpretation: ρ ranges from −1 to +1. ρ = 0.8 means strong positive monotonic relationship — as X increases, Y tends to increase, but the relationship need not be linear. Spearman can detect relationships that Pearson would miss (e.g., exponential or logarithmic relationships).

When to use: Ordinal data, non-normal continuous data, or when outliers are present. Spearman is robust to outliers because it uses ranks.

Friedman Test

Use: Non-parametric alternative to repeated measures ANOVA. For ≥ 3 related samples (same subjects measured at ≥ 3 time points).

How it works: Ranks each subject's values across conditions (1 to k per subject), then compares the sums of ranks across conditions.

Post-hoc: If Friedman is significant, use Conover's test or Wilcoxon signed-rank with Bonferroni correction for pairwise comparisons.

Essential Exam Facts

Chi-square (χ²): tests categorical association. χ² = Σ(O−E)²/E.
χ² df = (rows−1) × (columns−1). 2×2 → df=1.
Fisher's exact: when expected < 5 in >20% of cells, or any expected < 1.
McNemar's test: for paired categorical data. Uses only discordant pairs.
Mann-Whitney U: non-parametric alternative to independent t-test. Rank-based.
Wilcoxon signed-rank: non-parametric paired t-test. Tests median difference = 0.
Kruskal-Wallis: non-parametric ANOVA for ≥3 independent groups.
Spearman ρ: rank correlation. Detects monotonic (not just linear) relationships.
Friedman test: non-parametric repeated measures ANOVA for ≥3 time points.
Non-parametric tests have ~95% efficiency of parametric when assumptions are met.
⚠️ Common Exam Traps
• For contingency tables with expected < 5, use Fisher's exact, NOT chi-square.
• McNemar's is for PAIRED categorical data (before/after, matched pairs). Regular chi-square is for independent categorical data.
• Mann-Whitney tests if distributions are identical, NOT just medians (though often interpreted as a test of medians).
• Spearman detects monotonic relationships — a perfect Spearman ρ = 1 does not mean a perfect LINEAR relationship, only a perfect monotonic one.
• Yates' continuity correction reduces Type I error for 2×2 chi-square but is conservative. Fisher's exact is preferred.
🏥 Why This Matters Clinically

Treatment response (categorical outcomes): Many oncology trials use categorical endpoints (complete response, partial response, stable disease, progressive disease). Chi-square or Fisher's exact test compares response rates between treatment arms.

Diagnostic test agreement: McNemar's test compares paired proportions — e.g., comparing the proportion of positive results from a new diagnostic test vs the gold standard in the same patients. It tests whether the two tests differ in their classification rates.

Quality of life scores: QoL data from Likert scales is ordinal — use Mann-Whitney or Kruskal-Wallis for group comparisons, not t-tests or ANOVA. This is a common error in published oncology research.

Biomarker correlations: Spearman correlation is often more appropriate than Pearson for correlating biomarkers because biomarkers are often skewed and may have non-linear relationships (e.g., PSA and tumour volume).

Critical appraisal: When reading a paper, check whether non-parametric tests were used when appropriate. Common errors: using t-tests for ordinal data, using chi-square without checking expected frequencies, and using Pearson for non-linear relationships.

📐 Worked Examples

Scenario: A study of 40 patients compares two treatments. The 2×2 table shows: Treatment A: 2 improved, 18 not improved. Treatment B: 8 improved, 12 not improved. Can we use chi-square?

Solution: Expected frequencies: Row totals = 10, 30. Column totals = 10, 30.

Cell (A, improved): E = (10×10)/40 = 2.5 (expected < 5!).

Since expected frequencies < 5 in >20% of cells, use Fisher's exact test instead of chi-square.

Fisher's exact p-value (two-tailed) = 0.065 — not statistically significant.

Key insight: This is a classic FRCR exam scenario — always check expected frequencies before deciding between chi-square and Fisher's exact.

Scenario: 100 patients are tested with both a new rapid test and the gold standard. Results: Both positive = 40, both negative = 35, rapid positive/gold negative = 5, rapid negative/gold positive = 20. Do the tests differ significantly?

Solution: This is paired categorical data (two tests on same patients). McNemar's test: b = 5 (rapid +, gold −), c = 20 (rapid −, gold +).

χ² = (5 − 20)² / (5 + 20) = 225/25 = 9.0. df = 1. p = 0.003.

Conclusion: The two tests differ significantly. The rapid test misses 20 patients that the gold standard identifies — suggesting poor sensitivity.

Key insight: Note that concordant pairs (40+35=75) provide no information about the difference between tests. Only discordant pairs (5+20=25) matter.

Scenario: A study compares ECOG performance status (0–4) between two treatment groups. What test should be used?

Solution: ECOG is ordinal data. The appropriate test is Mann-Whitney U (non-parametric, for two independent groups with ordinal data).

Using an independent t-test (parametric) would be incorrect because ECOG is ordinal, not continuous. The mean and SD are inappropriate summary statistics for ordinal data.

Key insight: Always consider the data type before choosing the test. Ordinal data → non-parametric tests. This is one of the most frequently tested concepts in the FRCR exam.

🧠 Active Recall Questions

  • Q: When should you use Fisher's exact test instead of chi-square?
    A: When >20% of expected cell frequencies are <5, or any expected frequency is <1. Fisher's calculates the exact probability without relying on the chi-square approximation.
  • Q: What does McNemar's test compare, and why does it ignore concordant pairs?
    A: It compares paired categorical data (before/after, or two tests on same subjects). Concordant pairs (both same) provide no information about CHANGE or DIFFERENCE — only discordant pairs matter.
  • Q: What is the non-parametric alternative to: a) independent t-test, b) paired t-test, c) one-way ANOVA?
    A: a) Mann-Whitney U, b) Wilcoxon signed-rank, c) Kruskal-Wallis.
  • Q: What is the key difference between Pearson and Spearman correlation?
    A: Pearson measures LINEAR relationships. Spearman measures MONOTONIC relationships (using ranks). Spearman can detect non-linear monotonic relationships and is robust to outliers.
  • Q: What is the Friedman test and when is it used?
    A: Non-parametric alternative to repeated measures ANOVA. Used for ≥3 related samples (same subjects measured at ≥3 time points or conditions).
