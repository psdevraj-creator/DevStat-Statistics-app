1 · Getting Started

1 Launch & first run▶

Online: open https://dpsoncology.com and sign in.
Desktop Edition: extract the zip, double-click DevStatDesktopLauncher (Windows) or DevStat Desktop Edition.app (macOS). It opens in a clean, frameless browser window.

First run: create a free account → upload a file → inspect it → run an analysis. Your first 5 analyses + 5 charts are free; then a £25/year licence unlocks unlimited use (shared with the online app).

2 · Preparing Data

One row per subject, one column per variable. DevStat reads .csv, Excel (.xlsx/.xls), SPSS (.sav) and Stata (.dta).

2 Set types & labels (Variable View)▶

Open Data ▸ Variable View. For each variable set: type (Numeric / Date / String), measure (Nominal / Ordinal / Scale), decimals, label and value labels (e.g. code 1 = Male, 2 = Female).

3 Transform · compute & recode▶

Compute a new variable: Data ▸ Transform ▸ Compute — enter a name and an expression (e.g. bmi = weight / (height/100)^2).
Recode: Data ▸ Transform ▸ Recode — convert a value into a new code (e.g. group ages into bands).

4 · Compare Means

8 Independent-samples t-test▶

Path: Analyze ▸ Compare ▸ Compare Means (Independent t-test)
Steps: dependent variable (continuous) + grouping variable (2 groups) → Run.
Output: mean difference, 95% CI, t, df, p; Levene's test tells you whether to read the equal- or unequal-variance row.

9 Paired / related t-test▶

Path: Analyze ▸ Compare ▸ Paired t-test
Steps: select the two repeated measures → Run.
Output: mean within-pair difference, CI, t and p.

10 One-way ANOVA▶

Path: Analyze ▸ Compare ▸ One-way ANOVA
Steps: dependent (continuous) + factor (2+ groups) → Run.
Output: F ratio and p; effect size (eta²); a post-hoc comparison if you request one.

11 Factorial ANOVA▶

Path: Analyze ▸ Compare ▸ Factorial ANOVA
Steps: dependent + two factors → Run.
Output: main effects for each factor and the interaction; F and p for each.

12 · Interpreting the Output

Every result comes with a plain-English interpretation. The three numbers to read first:

  • p-value — chance of the data if there were really no effect. Report the value, not just "<0.05".
  • 95% confidence interval — the range of plausible true values. Excluding the null value is consistent with significance.
  • Effect size — how big the difference is (Cohen's d, eta², odds/hazard ratio). Often more clinically important than p.
p < 0.05 is not special. Tiny p on a huge sample or a large effect on a tiny sample both deserve a sentence about clinical importance. Always report effect sizes + CIs too.

14 · Glossary & FAQ

p-value
Probability of the data if there were no effect — not the probability the effect doesn't exist.
Confidence interval
Range of plausible true values for the effect.
Effect size
Standardised magnitude of a difference/association.
Null hypothesis
The "no effect" baseline the test is evaluated against.
Power
Chance of detecting a real effect; grows with sample size / effect size.
Type I / II error
False positive / false negative.
Hazard ratio
Ratio of event rates over time (Cox); <1 favours the first group.
