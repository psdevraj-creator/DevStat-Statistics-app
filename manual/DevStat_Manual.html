DevStat — User Manual

Medical Statistics Software · Statistical analysis and visualisation of clinical data

This manual walks through every feature using real worked examples. All screenshots were generated from the included sample medical dataset (large clinical dataset with demographic, laboratory, treatment, and outcome variables).

1. Getting started

1.1 What DevStat does

DevStat is a desktop application for analysing clinical data — like a modern, easy-to-use version of SPSS. You load a dataset, choose a statistical test or chart, and get clear results you can view, export, and interpret.

  • Import CSV, Excel, SPSS (.sav), and Stata (.dta) files
  • View and edit data in a spreadsheet-style grid with SPSS-style variable metadata
  • Run descriptive statistics, group comparisons, regression, survival, diagnostic tests, factor/reliability, cluster, and power analyses
  • Create 27+ chart types and export results to PDF and images

1.2 Loading your data

Go to Data → Data View and click the Upload button. Choose your file. The data grid appears with rows and columns; the status bar shows the shape of the dataset (e.g. rows × columns).

For every example in this manual we use the sample medical dataset. Typical columns include:

2. Descriptive statistics

2.1 Descriptives

Analyze → Descriptive. Summarise one or more continuous variables (mean, standard deviation, minimum, maximum, skewness, kurtosis). Select variables and optionally a group to split results.

2.2 Frequencies

Show the count and percentage of each category for a categorical variable (e.g. smoking_status). Optionally display a bar chart.

2.3 Crosstabs

Cross-tabulate two categorical variables and get the chi-square test of association. Useful for checking whether two categories are related (e.g. treatment group × outcome).

2.4 Explore (normality)

Get descriptive statistics per group, plus normality tests (Shapiro–Wilk), Q–Q plots, and boxplots. Especially useful before choosing a test.

2.5 Means

Compare the mean of a continuous variable across groups, with confidence intervals.

3. Comparing means and groups

3.1 Independent-samples t-test

Analyze → Compare Means → Independent t-test. Compares the mean of a continuous variable between two unrelated groups (e.g. BMI by gender). Includes Levene's test for equal variances.

3.2 Paired t-test

Compare two measurements taken on the same subjects (e.g. systolic vs diastolic blood pressure).

3.3 One-way ANOVA

Compares the mean of a continuous variable across three or more groups (e.g. cholesterol by treatment group), with optional Tukey post-hoc tests.

3.4 Non-parametric tests

Use these when data are not normally distributed or you have small samples:

  • Mann-Whitney U — two independent groups (image below)
  • Wilcoxon signed-rank — paired data
  • Kruskal-Wallis — three or more groups
  • Chi-square / Fisher's exact — categorical association
  • Friedman, McNemar, Binomial, Runs, Kolmogorov-Smirnov

4. Correlation and regression

4.1 Correlation

Analyze → Correlation. Compute a matrix of correlations between continuous variables (Pearson or Spearman). Optionally partial correlation controlling for a third variable.

4.2 Linear regression

Model a continuous outcome from one or more predictors (e.g. systolic BP from age, BMI, cholesterol). Reports R², the ANOVA table, coefficients, and p-values.

4.3 Logistic regression

Model a binary outcome (e.g. diabetes yes/no) from predictors. Reports odds ratios and Wald statistics.

5. Survival analysis

5.1 Kaplan-Meier

Survival → Kaplan-Meier. Time-to-event analysis with a time variable and a status (event) column. Produces the survival curve, median survival, and log-rank test.

5.2 Cox regression

Model the hazard of an event from covariates. Reports hazard ratios and confidence intervals.

6. Diagnostic tests and ROC

6.1 Diagnostic test

Compare a test against a gold standard. Produces the 2×2 table (TP, FP, FN, TN) plus sensitivity, specificity, PPV, NPV, and accuracy.

6.2 ROC curve

Plot the receiver operating characteristic curve for a continuous test variable against a binary outcome, with the area under the curve (AUC).

7. Factor analysis, reliability, and clustering

7.1 Factor analysis

Identify underlying factors among many variables. Reports KMO, Bartlett's test, factor loadings, and variance explained.

7.2 Reliability (Cronbach's alpha)

Assess internal consistency of a scale using Cronbach's alpha.

7.3 Cluster analysis

Group observations by similarity (k-means or hierarchical), producing cluster sizes, centroids, and a silhouette score.

8. Power analysis

Determine the sample size needed to detect a given effect (t-test, ANOVA, or correlation) at a chosen power and alpha.

9. Graphs and charts

The Graphs menu offers a gallery of chart types. All are interactive: hover for values, zoom, and export to PNG.

10. Output, export, and saving

  • Output — a running list of every analysis performed, organised by category. Select items to compare side by side.
  • Export — results as PDF, charts as PNG, and the dataset as CSV, Excel, SPSS (.sav), or Stata (.dta).
  • Save / Load project — save your current dataset and analysis view to a .devstat file for later.

11. A short guide to interpreting output

Reading a p-value

A p-value (< 0.05) suggests the result is statistically significant — unlikely to be due to chance. It does not tell you how large the effect is; look at the estimate (mean difference, hazard ratio, correlation) and its confidence interval for practical importance.

Choosing the right test

Use the Wizard or Suggest Test feature: answer a few questions about your goal, variable types, and design, and DevStat recommends an appropriate test. Hover over any test or chart card in the gallery to see what it is for and whether your current data are suitable.

Common pitfalls

  • Normality — use the Explore feature (Shapiro–Wilk). If data are not normal, prefer a non-parametric test.
  • Multiple testing — correct for many comparisons (e.g. Tukey post-hoc after ANOVA).
  • Confidence intervals — a wide interval means an imprecise estimate (often a small sample or few events, e.g. high censoring in survival data).
