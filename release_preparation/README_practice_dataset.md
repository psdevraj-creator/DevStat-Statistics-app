# DevStat — Practice dataset & "Learn as you do"

This dataset is the purpose-built practice file that accompanies the FRCR Part 1
Medical Statistics module's **"Learn as you do"** exercises. Download it, open it in
DevStat, and follow the step-by-step tasks — every exercise produces a clear,
reproducible result.

## What's in it
- **240 synthetic patients**, **14 columns** — deliberately built so each of the
  ~112 exercises in the module produces a clean, interpretable result.
- Columns: `patient_id, age, sex, bmi, treatment (Drug A / Drug B / Placebo),
  systolic_bp, cholesterol, smoking, pain_score, outcome, new_biomarker,
  gold_standard, followup_months, event_death`.

## How to use it
1. **Download** `devstat-practice-data.csv` (the file in this release).
2. Open DevStat → **Data → Upload** → choose this file.
3. Go to the module's **"Learn as you do"** page and work through the exercises,
   following each task's menu path and checking your result against the
   self-check.

## Where to get the module
The FRCR 1 Study Hub statistics module (with the guided exercises) is at
`https://psdevraj-creator.github.io/DevStat-Statistics-app/` (Medical Statistics →
**Learn as you do**).

> ⚠ This is **synthetic** data for **exam practice only** — it is not real patient
> data and must not be treated as such.
