# DevStat — Practice dataset & "Learn as you do"

This dataset is the **purpose-built synthetic practice file** for the FRCR Part 1
Medical Statistics module's **"Learn as you do"** exercises. Download it, open it
in DevStat, and follow the step-by-step tasks.

## Contents
- **240 synthetic patients**, **14 columns** — built so every exercise produces a
  clear, reproducible result.
- Columns: `patient_id, age, sex, bmi, treatment (Drug A / Drug B / Placebo),
  systolic_bp, cholesterol, smoking, pain_score, outcome, new_biomarker,
  gold_standard, followup_months, event_death`.

## How to use
1. **Download** `devstat-practice-data.csv`.
2. Open DevStat → **Data → Upload** → choose this file.
3. Work through the **"Learn as you do"** exercises in the FRCR statistics module
   (follow each task's menu path, check your result against the self-check).

## Module
FRCR 1 Study Hub → Medical Statistics → **Learn as you do**:
`https://psdevraj-creator.github.io/DevStat-Statistics-app/`

> ⚠ **Synthetic, exam-practice only** — not real patient data. For real
> (anonymised) analysis use the offline desktop app.
